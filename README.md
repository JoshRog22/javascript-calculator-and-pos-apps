# JavaScript Calculator & Point-of-Sale Applications

A collection of interactive JavaScript applications demonstrating fundamental programming concepts, user input processing, calculations, conditional logic, and dynamic webpage updates.

## Applications

### Rectangle Calculator
Calculates the area and perimeter of a rectangle based on user-provided length and width values.

### Olympic Judging Calculator
Processes scores from multiple judges and calculates a final score after removing the highest and lowest scores.

### Point-of-Sale System
An interactive shopping cart that allows users to select products, specify quantities, add items to a cart, and calculate a running total.
